# GanttManager — Серверная система для интерактивной диаграммы Ганта

Рабочий прототип (MVP) серверной части для управления проектами. Мы создали стабильный бэкенд и базу данных, объединили их с математическим алгоритмом Ганта и развернули всю систему в интернете. 

--------------------------

# Главная фишка: Автономная работа в облаке

Наш бэкенд и база данных **полностью перенесены с локальных компьютеров на удаленный облачный сервер (Relax.dev)**

--------------------------

# Стек технологий

Мы выбрали максимально надежные инструменты, чтобы связать бэк, базу и фронтенд:

- **.NET 8 Web API (C#):** Современный и ультрабыстрый серверный движок от Microsoft.
- **PostgreSQL 15:** Профессиональная база данных.
- **Entity Framework Core:** Инструмент, который позволил нам автоматически построить таблицы в базе данных прямо из C# кода без ручного написания SQL-запросов.
- **Docker & Docker Compose:** Использовался для контейнеризации и быстрой настройки базы данных на компьютерах разработчиков, исключая конфликты с Windows.
- **CORS (AllowAll):** Специальная настройка сетевой безопасности в коде сервера. Она разрешает удаленному облачному бэкенду без ошибок принимать и отправлять данные на локальные компьютеры наших фронтендеров на React.

--------------------------

# Реализованный функционал

- Интерактивное управление проектами: Возможность динамически создавать, выбирать и удалять отдельные проекты через единую панель управления.
- Визуализация календарного планирования (Диаграмма Ганта): Наглядное отображение сроков, длительности и последовательности выполнения всех процессов на удобном графическом таймлайне.
- Умный автоматический пересчет графиков: Интеллектуальный сдвиг временных рамок связанных между собой задач при изменении сроков любой из них.
- Дашборд аналитики и метрик: Автоматический подсчет общего количества задач и их быстрая группировка по текущим статусам выполнения в реальном времени.
- Интеллектуальный контроль дедлайнов и рисков: Встроенная система мониторинга критических сроков, которая мгновенно предупреждает пользователя, если финал проекта выходит за рамки общего дедлайна.
- Удобная навигация и фильтрация: Инструменты оперативного изменения масштаба временной сетки (день/неделя) и мгновенный текстовый поиск по названию операций.
